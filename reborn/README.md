# Reborn 重生 · 可运行原型

《Reborn》戒色康复 APP 的**可运行实现**。产品规划文档见 [`../docs/reborn/README.md`](../docs/reborn/README.md)。

## 运行

`reborn/index.html` 是一个**自包含单文件应用**——没有构建步骤，没有依赖，没有后端。

```bash
# 直接打开
open reborn/index.html

# 或起个静态服务（手机访问时用）
python3 -m http.server 8000 --directory reborn
```

### 交互细节

- 顶栏三点菜单：7 个快捷入口
- 落地页：关于/隐私/常见问题三个链接 + 免责声明
- 深浅双主题（token 级实现，两套配色分别调校）+ 手动切换
- 字号 85%–130% 无级缩放
- 动画总开关，另外自动尊重 `prefers-reduced-motion`
- 「隐藏天数」模式：数字压力大时可关掉显示
- 跨天自动刷新、时段彩蛋（深夜/清晨/复发次日）
- Esc 关闭面板、键盘焦点可见、图表带 `aria-label`、开关用 `role="switch"`
- 空状态、锁定态、已完成态均有对应设计

## 技术说明

- **无后端**：全部状态存在 `localStorage`（key `reborn.state.v1`），不联网、不上传。隐私模式下自动降级到内存存储。可导出 JSON 备份、导入还原。
- **单文件**：约 190 KB，内联全部样式与脚本，零依赖、零构建、零网络请求。断网可用。
- **教练对话**是基于 CBT 原则编写的**脚本化决策树**（26 个节点），不是 LLM。界面内已明确标注。
- **主题**：跟随系统深浅色，也可手动切换（token 级实现，两套配色均单独调校）。
- **无障碍**：键盘焦点可见、Esc 关闭面板、图表带 `aria-label`、尊重 `prefers-reduced-motion`。

## 与文档规划的差异

文档 8.1 规划的技术栈是 React Native + Supabase + GPT-4o-mini。本原型改为**纯前端单文件**，目的是让方案立刻可试用、可验证交互，无需注册与部署。以下功能属于需要后端或原生能力的部分，尚未实现：

- 网站/应用拦截与卸载保护（需原生 VPN/辅助权限）
- 真实在线社区与导师问答（心声墙是本地示例 + 本地发布，界面内已标注；问责伙伴是本地联系人 + 系统拨号，应用不会自动通知任何人）
- 真实 LLM 教练（需 API 与密钥托管）
- 后台推送（应用内有基于 Notification API 的每日提醒，但标签页关闭后不保证送达；真正的后台推送需 Service Worker + 推送服务）
- 功法教学视频与冥想音频（需内容生产与 CDN）
