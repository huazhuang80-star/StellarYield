# 鱼乐达人 (Yulida Ren)

一款原创的浏览器端捕鱼游戏，向街机 / 手机端捕鱼品类致敬。**并非任何已发行商业产品的复刻**——所有美术资源（鱼群、炮台、鱼网、金币、道具、Boss、背景）均由 Canvas 2D 路径与渐变在运行时程序化绘制，音效由 Web Audio 合成，数值与代码均为原创。

## 运行

游戏是纯静态站点，无构建步骤，无外部依赖。用任意静态服务器打开 `yulida-ren/index.html` 即可：

```bash
cd yulida-ren
python3 -m http.server 8000
# 然后访问 http://localhost:8000/
```

> 由于使用了 ES 模块 (`<script type="module">`)，请通过 HTTP 打开，不能直接双击 `file://` 打开。

## 玩法

- **瞄准**：鼠标 / 手指移动即瞄准，炮台跟随光标。
- **发射**：点击 / 触摸屏幕发射炮弹。
- **鱼网**：炮弹命中鱼后弹出鱼网，对范围内所有鱼造成伤害；血量归零即捕获。
- **炮台等级**：底部 `-` / `+` 切换 1–10 级；等级越高伤害越大、每发消耗越多，随时可切换。
- **连击**：3 秒内连续捕获 3 条以上会开启金币倍率（1.5 × → 2 × → 3 × → 5 ×）。
- **道具**：击杀鲨鱼 / 金龙 / Boss 有概率掉落 ❄ 冰冻、💣 海炸、⚡ 闪电；顶部道具槽点击或按 `1` / `2` / `3` 使用。
- **鱼群**：每 30 秒会出现一波同种小鱼群（6–10 条）。
- **成就**：满足条件自动解锁，右上角滑入提示。
- **暂停 / 静音 / 连发 / 设置**：右上角 HUD 芯片。
- **设置面板**：⚙ 按钮打开，可重置存档、切换声音。
- **持久化**：金币、炮台等级、道具存量、最大连击、已击杀鲨鱼 / 金龙 / Boss 计数、成就解锁记录、静音 / 连发偏好，全部自动存到浏览器 `localStorage`。

## 模块划分

```
yulida-ren/
├── index.html           # 入口
├── styles.css
├── README.md
└── src/
    ├── main.js          # 引导 + Canvas roundRect polyfill
    ├── config.js        # 全部常量 / 数值 / 道具 / 成就表
    ├── storage.js       # localStorage 存档（含道具 / 成就 / 战绩）
    ├── audio.js         # Web Audio 合成音效（含道具三音）
    ├── input.js         # 鼠标 / 触摸输入 + letterbox 坐标反算
    ├── sprites.js       # 程序化矢量绘制（12 种鱼 + 炮台 + 子弹 + 网 + 金币 + 道具 + 火焰）
    ├── scene.js         # 海底背景、光柱、海草、气泡
    ├── fish.js          # Fish 类 + Spawner（直线 / 正弦 / 弧线 / 鱼群 + 冻结感知）
    ├── bullet.js        # Bullet + Net（范围伤害）
    ├── cannon.js        # 炮台瞄准、开火、发射节流
    ├── particles.js     # 金币 / 浮字 / 气泡 / 火花
    ├── items.js         # 道具掉落 + 三种道具效果 + 电击 / 爆炸可视化
    ├── achievements.js  # 成就检查器 + 解锁 Toast
    ├── ui.js            # HUD / 芯片 / 道具槽 / 连击 / 开始 / 暂停 / 设置 / Boss 警告
    └── game.js          # 主循环 + 屏幕震屏 + 炮口闪光
```

## 已实现的功能（v0.2）

- 12 种鱼，程序化矢量绘制，尾巴摆动 / 水母收缩 / 龙须飘动 / Boss 触手波动
- 直线 / 正弦 / 弧线 / 鱼群 4 种游动模式，波次随时间加快
- 每 45 秒概率触发金龙，每 90 秒触发海皇 Boss，警告横幅 + 低音警报
- 10 级炮台，10 种配色，随等级递增伤害与消耗
- 炮弹 + 网状范围伤害，一次网可同时击杀多条鱼
- 3 种道具：冰冻 / 海炸 / 闪电，掉落 → 存档 → 使用
- 连击系统：3 秒窗口，1× → 1.5× → 2× → 3× → 5×，金币按倍率结算
- 10 个成就，满足即滑入 Toast
- 屏幕震屏（海炸使用 / Boss 死亡）+ 炮口闪光（发射瞬间）
- 金币掉落粒子 + 命中飞溅火花 + 上浮气泡 + 浮动 +N 文字（带连击色）
- 合成音效：发射（方波）、命中（带通噪声）、入账（三和弦琶音）、Boss 警告（锯齿）、冰冻（下滑正弦）、海炸（低通噪声）、闪电（高通噪声）、成就（琶音）、升级
- 环境音乐：低频正弦 + LFO 颤音 + 中频三角形 pad
- 连发（长按自动开火，节流 320ms）
- 桌面鼠标 + 移动触屏输入，letterboxed 逻辑坐标
- 手机竖屏自动检测并显示「请横屏游玩」提示，首次点击尝试 `screen.orientation.lock('landscape')`
- 开始 / 暂停 / 设置 三层覆盖界面；`P` 键快捷暂停；`1` / `2` / `3` 快捷道具
- 设置面板可重置存档、切换声音
- 全量 localStorage 存档
