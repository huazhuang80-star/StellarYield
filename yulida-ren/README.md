# 鱼乐达人 (Yulida Ren)

一款原创的浏览器端捕鱼游戏，向街机 / 手机端捕鱼品类致敬。**并非任何已发行商业产品的复刻**——所有美术资源（鱼群、炮台、鱼网、金币、背景）均由 Canvas 2D 路径与渐变在运行时程序化绘制，音效由 Web Audio 合成，数值与代码均为原创。

## 运行

游戏是纯静态站点，无构建步骤，无外部依赖。用任意静态服务器打开 `yulida-ren/index.html` 即可：

```bash
cd yulida-ren
python3 -m http.server 8000
# 然后访问 http://localhost:8000/
```

> 由于使用了 ES 模块 (`<script type="module">`)，请通过 HTTP 打开，不能直接双击 `file://` 打开。

## 玩法

- **瞄准**：鼠标 / 手指移动即瞄准，炮台跟随光标。
- **发射**：点击 / 触摸屏幕发射炮弹。
- **鱼网**：炮弹命中鱼后弹出鱼网，对范围内所有鱼造成伤害；血量归零即捕获，获得金币。
- **炮台等级**：底部 `-` / `+` 切换 1–10 级，等级越高伤害越大、每发消耗越多，随时可切换。
- **连发**：右上角 `连发` 切换按住不放自动开火。
- **声音**：右上角 `声音` 静音切换。
- **暂停**：右上角 `⏸` 暂停 / 继续。
- **持久化**：金币、炮台等级、总捕获数、设置自动存到浏览器 `localStorage`。

## 模块划分

```
yulida-ren/
├── index.html           # 入口
├── styles.css
├── README.md
└── src/
    ├── main.js          # 引导 + Canvas roundRect polyfill
    ├── config.js        # 全部常量 / 数值表
    ├── storage.js       # localStorage 存档
    ├── audio.js         # Web Audio 合成音效
    ├── input.js         # 鼠标 / 触摸输入 + letterbox 坐标反算
    ├── sprites.js       # 程序化矢量绘制（10 种鱼 + 炮台 + 子弹 + 网 + 金币）
    ├── scene.js         # 海底背景、光柱、海草、气泡
    ├── fish.js          # Fish 类 + Spawner（直线 / 正弦 / 弧线路径）
    ├── bullet.js        # Bullet + Net（范围伤害）
    ├── cannon.js        # 炮台瞄准、开火、发射节流
    ├── particles.js     # 金币 / 浮字 / 气泡 / 火花
    ├── ui.js            # HUD、按钮、开始 / 暂停 / Boss 警告
    └── game.js          # 主循环
```

## 已实现的功能

- 10 种鱼，程序化矢量绘制，尾巴摆动动画
- 直线 / 正弦 / 弧线三种游动路径 + 随机速度、幅度、相位
- 波次随时间加快（4 分钟内从 900ms 缩至 320ms 生成间隔）
- 每 45s 概率触发金龙，每 90s 触发海皇 Boss，附赠警告横幅 + 低音警报
- 10 级炮台，10 种配色，随等级递增伤害与消耗
- 炮弹 + 网状范围伤害，一次网可同时击杀多条鱼
- 金币掉落粒子 + 命中飞溅火花 + 上浮气泡 + 浮动 +N 文字
- 合成音效：发射（方波）、命中（带通噪声）、入账（三和弦琶音）、Boss 警告（锯齿）
- 环境音乐：低频正弦 + LFO 颤音 + 中频三角形 pad
- 连发（长按自动开火，节流 320ms）
- 桌面鼠标 + 移动触屏输入，letterboxed 逻辑坐标
- 暂停 / 静音 / 开始画面
- localStorage 存档：金币、炮台等级、总捕获、静音、连发

## 与商业产品的区别
