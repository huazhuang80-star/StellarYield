# 西宁自建房设计方案 · Tây Ninh House Design

10 × 32 m 农村地块的两层四卧住宅 + 全院庭院设计方案，含转地契与填土费用的完整预算（削减后 $39,105，上限 4 万美金）。

## 文件

- `index.html` — 完整方案（单文件，自包含，无外部依赖）— **交付物**
- `geom.js` — 场景几何源码：尺寸定义、墙体与门洞、家具洁具、场地与庭院、植物与禽舍
- `viewer.js` — 渲染器源码：数学、材质、网格构建、着色器、太阳位置、相机、漫游、UI
- `viewer.v1.js` — 上一版渲染器备份
- `splice.py` — 构建脚本：`geom.js` → `viewer.js` → `index.html` 内联
- `walkthrough-storyboard.png` — 48 格漫游分镜连拍图（从实时渲染逐帧截取）

改几何编辑 `geom.js`，改渲染器编辑 `viewer.js`，然后 `python3 splice.py` 重新构建。
`splice.py` 会先把 `geom.js` 替换进 `viewer.js` 的第 4–19 节，再把整个 `viewer.js`
内联进 `index.html`，所以两个源文件都不能手动改 `index.html` 里的副本。

## 技术说明

**三维渲染**：手写 WebGL2 渲染器，不依赖任何三维库。约 5.7 万三角面、11.6 万顶点、62 种材质。

- 2048² 深度贴图 + 硬件 PCF（3×3）软阴影
- 程序化材质：砖缝错缝、瓷砖分格、木纹、金属瓦楞、混凝土骨料与伸缩缝、草地双尺度噪声
- 菲涅尔玻璃、动态波纹水面、半球环境光 + 8 盏室内点光源（半兰伯特近似反弹光）
- 大气雾、ACES 色调映射、程序化天空（含日落色温变化与夜间星空）
- 墙体按洞口切分生成，窗洞是真开的；家具、洁具、橱柜、楼梯踏步均建模

**日照模拟**：按西宁真实坐标（11.31°N, 106.10°E, UTC+7）计算太阳赤纬、时角、
真太阳时（含均时差修正）与高度角/方位角，阴影为该日期时刻的真实阴影。

**图纸**：总平面、平面、立面、剖面由房间与墙体数据在运行时生成 SVG，
与三维模型共用同一套尺寸定义（`geom.js` 中的 `D`、`index.html` 中的 `FLOORS`），因此图纸与模型不会失配。

**动线校核**：漫游路线按真实步行动线布点（55 个航点），每一段直线都落在同一个房间或
走廊内，过墙必定垂直穿过实际门洞。渲染器暴露了一个机位净空探针
`window.__tn.probe([x,y,z])`，返回相机点到各几何组最近顶点的距离，用来自动查出
「机位卡在家具/树里」「漫游路线穿墙」这类问题；`window.__tn.eye()` 返回当前相机位置，
配合 `__tn.set({tour:t})` + `__tn.frame()` 可以沿路线逐点扫描。

预算数据来源见方案页脚。汇率 26,300 VND/USD（2026 年 7 月）。
