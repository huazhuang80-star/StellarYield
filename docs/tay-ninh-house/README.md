# 西宁自建房设计方案 · Tây Ninh House Design

10 × 32 m 农村地块的两层四卧住宅 + 全院庭院设计方案，含转地契与填土费用的完整预算（总额 $39,536，上限 4 万美金）。

## 文件

- `index.html` — 完整方案（单文件，自包含，无外部依赖）

| 01 | 设计策略 — 六个把造价压进 4 万美金的关键决定 |

| 04 | 一层 / 二层平面图 1:100 + 房间面积明细 |

## 技术说明

3D 效果图为纯 JavaScript 软件渲染器（Canvas 2D，画家算法 + 平面着色 + 投影阴影），
不依赖 WebGL 或任何外部库。平面图、立面图、剖面图由房间与墙体数据在运行时生成 SVG，
与 3D 模型共用同一套尺寸定义。

预算数据来源见方案页脚。汇率 26,300 VND/USD（2026 年 7 月）。
